# dannyluu.com

Source for Danny Luu's personal website, hosted with GitHub Pages at [www.dannyluu.com](https://www.dannyluu.com/).

The site is intentionally dependency-free: one HTML document, local images, and no build step, analytics, or third-party JavaScript.

## Local preview

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.
